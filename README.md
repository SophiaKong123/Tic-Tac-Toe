# Tic-Tac-Toe
I created a Tic Tac Toe game with a 3x3 grid where two players take turns placing Xs and Os. The game tracks moves using a 2D array and checks for a winner by summing rows, columns, and diagonals. It displays win, loss, or tie messages and updates scores. Players can reset the board and play again, making for a smooth and engaging experience!
